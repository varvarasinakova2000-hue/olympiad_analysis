# Аналитика результатов олимпиады

Полный цикл работы с данными олимпиады для школьников: разведочный анализ, очистка,
производные метрики, анализ сложности заданий, региональная аналитика с автоматическими отчётами,
проверка статистических гипотез и выводы для бизнеса.

**Данные:** 8 037 прохождений, 10 регионов, 590 школ, 12 заданий, 5–11 классы, 10 апреля 2026 года.

## Структура проекта

| Файл / папка | Что внутри |
|---|---|
| `olympiad_analysis.ipynb` | основной ноутбук: весь анализ от загрузки до выводов |
| `presentation.pptx` | итоговая презентация с ключевыми выводами |
| `data/olympiad_results.csv` | исходная выгрузка |
| `data/olympiad_data_dictionary.csv` | словарь данных |
| `data/olympiad_results_clean.csv` | очищенный и обогащённый датасет: 7 928 строк × 59 столбцов |
| `reports/` | автоматические PDF-отчёты по каждому из 10 регионов |
| `power_bi/` | витрины для дашборда: два справочника и три таблицы фактов |
| `dashboard.pbix` | дашборд в Power BI |
| `dashboard example (MSK).pdf` | пример дашборда с фильтром по Москве |

## Как запустить

Нужны Python 3.10+ и библиотеки `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy`, `jupyter`.

```bash
pip install pandas numpy matplotlib seaborn scipy jupyter
jupyter notebook olympiad_analysis.ipynb
```

Ноутбук выполняется целиком примерно за 30 секунд и сам создаёт очищенный датасет,
папку `reports/` с отчётами и папку `power_bi/` с витринами.

Мини-отчёт по любому региону строится одной строкой:

```python
region_report('Москва')        # KPI, выводы, топ-школы, результаты по классам, 4 графика
export_region_pdf('Москва')    # тот же отчёт в PDF
```

## Очистка данных

Из 8 037 строк в анализ вошли **7 928**:

- удалены 37 полных дубликатов;
- удалены 72 аномальные сессии: ~20 секунд на все 12 заданий, 1–3 секунды на задание,
  доля верных ответов 23 % — статистически не отличается от случайного угадывания (биномиальный тест, p = 0,22);
- 19 вариантов написания регионов приведены к 10 эталонным («мск», «Moskva», «г.Казань», «СПб»);
- пропуски в заданиях оставлены как есть: это пропущенные учеником задания, они засчитаны как 0 баллов.

## Ключевые выводы

1. **Самые сложные задания — 1, 9 и 3** (решаемость 29–33 %), самые лёгкие — 5, 8 и 4 (57–61 %).
   На сложные задания тратят *меньше* времени (64–66 сек против 79–81), и на них в 5–8 раз больше
   ответов быстрее 5 секунд: трудную задачу не дорешивают, а угадывают.
2. **Вовлечённость одинакова во всех классах** — все 12 заданий проходят 60–64 % участников,
   а средний балл растёт от 4,50 в 5 классе до 6,62 в 11-м. Для младших олимпиада слишком сложная.
3. **Регионы не различаются**: разброс средних 5,38–5,73 балла, p = 0,37.
4. **Школы тоже не различаются сильнее случайного**: школ с заметным отклонением 26 при ожидаемых 27.
   При ~13 участниках от школы рейтинг по одному туру отражает удачу, а не подготовку.
5. **Устройство, часовой пояс, разрывы связи и час старта на результат не влияют.**
